# Práctica de Desarrollo Web - One Piece Fanpage

## Descripción
Página web con personajes y villanos de One Piece utilizando HTML, CSS y JavaScript.

## Ramas y Control de Versiones

### Rama 1: Código HTML básico
```bash
git checkout -b rama1-html
git add index.html
git commit -m "Añadido HTML básico"
git push origin rama1-html
```

### Rama 2: Agregar header, section, footer y CSS básico
```bash
git checkout -b rama2-css
git add estilos.css index.html
git commit -m "Añadidos header, section, footer y CSS básico"
git push origin rama2-css
```

### Rama 3: Añadir script básico con JavaScript
```bash
git checkout -b rama3-js
git add script.js index.html
git commit -m "Añadido JavaScript básico"
git push origin rama3-js
```

### Rama 4: Añadir función para cambiar fondo y explicación completa
```bash
git checkout -b rama4-funcion
git add script.js index.html
git commit -m "Añadida función cambiar fondo y explicación"
git push origin rama4-funcion
```

### Rama 5: Mejoras en CSS y responsividad
```bash
git checkout -b rama5-css-responsivo
git add estilos.css
git commit -m "Mejoras en CSS y responsividad"
git push origin rama5-css-responsivo
```

### Rama 6: Funcionalidad completa y publicación en GitHub Pages
```bash
git checkout -b rama6-publicacion
git add .
git commit -m "Funcionalidad completa y lista para publicación"
git push origin rama6-publicacion
